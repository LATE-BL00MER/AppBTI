## 안건별 확인 질문

### 7. 이용시간 지표
- `AVG_ASMP_VSIT_TM`의 단위·정의 답변이 왔는가? 안 왔으면 언제까지 기다리고 그 뒤에는 어떻게 하는가?
- 보조 지표로 보인다면 화면에 단위를 어떻게 적는가? 단위를 추측해 변환하지 않는다.

### 1. 설문 문항
- 후보마다 "왜 이 문항인가?"에 답할 수 있는 근거 수치가 있는가?
- 대분류가 한쪽으로 몰리지 않았는가? 설문에 쓰는 대분류만 화면에 노출한다.
- 문항 수가 많으면 응답 시간은 얼마인가? (시연 3분 안에 끝낼 수 있는지)

### 2. 유사도 설정
- 0일 응답을 제외하는가, 포함하는가? 평균 이용일수 분모 답변 전 기본값은 무엇인가?
- 최소 비교 개수 미만이면 `status=insufficient`로 세대별 탐색을 안내한다. 이 개수는 몇 개인가?
- 가중치를 둔다면 근거가 있는가? 없으면 동일 가중치로 시작한다.

### 3. 결과 유형
- 유형 이름이 실제 나이 판정이나 성격 유형(MBTI식)처럼 보이지 않는가?

### 4. API 응답 형태
- 프론트가 쓰는 필드 이름을 이날 고정한다. 이후 바꾸면 단톡에 알리고 예시 JSON을 같이 고친다.
- 결측은 모두 `null`이고 화면은 "데이터 없음"으로 보인다.
- 대분류 점수 산식(우서현, 11/12)이 없을 때 레이더는 숨기는가, 비워 두는가?

### 5. Figma 수정 범위
- 데이터가 없는 요소(시간대별 잠금 해제, 푸시 알림 등)는 모두 빠졌는가?
- 출처·범위 문구("LG U+ 제공 연령대·기간(2025년 1~6월) 집계") 위치는 어디인가?

### 6. 저장소·브랜치
- 이전한다면 누가, 언제 하는가? 팀원 GitHub 아이디를 받았는가?

### 8. 발표 구성
- 시연이 실패하면 백업 영상으로 넘어가는 신호와 담당자는 누구인가?
