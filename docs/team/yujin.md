### 구조와 기존 동작
- `main.tsx` → `App.tsx`: 라우팅과 공통 레이아웃, 탐색 지연 로딩.
- `components/AppLayout.tsx`: 헤더·모바일 메뉴·푸터·예시 데이터 배지·메타 오류 처리.
- `pages/`: Intro, Survey, Result, Explore, AboutData.
- `api/types.ts`: `Questions`의 문항·최대 일수·시간 가용성·비교 정책, `Answer`의 minorCode/days/minutes 유지.
- `api/client.ts`: 요청·오류·타임아웃·재시도. 설문은 GET `/api/survey/questions`, 결과는 POST `/api/survey/result` 사용.
- `state.tsx`: 탭별 sessionStorage 응답 보관. 분야 이동 시 응답 유지, 데이터셋 변경 시 초기화.
- `design.css`: 기존 청회색 토큰·반응형 스타일. Figma 대조 전 기존 공통 스타일 유지.

### 이번 반영
- 상단 현재 분야·전체 분야 수·전체 응답 수·진행바.
- 대분류 헤더 구분선, 5개 정확한 일수 선택지, 직접 입력(0~31일 및 API maxDays 상한).
- 빈 직접 입력은 null, 0일은 0으로 유지. 음수·소수·상한 초과는 응답에 반영하지 않음.
