# 팀 시연 가이드

로컬 서버 실행 후 http://127.0.0.1:5173 을 연다. 현재 화면은 실제 데이터가 아닌 가상 통계 기반이다.

## 5분 시연 순서

1. **소개**: 서비스의 목적, 데이터 범위, 결과의 의미를 설명한다. ‘예시 결과 먼저 보기’를 누르면 설문 없이 리포트를 볼 수 있다.
2. **설문**: 6개 분야의 12개 중분류에 답한다. 선택지는 대표 일수로 변환되며 ‘사용 안 함’과 ‘잘 모르겠어요’를 구분한다. 최소 4개가 비교 가능해야 한다.
3. **결과**: 유사한 가상 집단, 전체 집단 점수, 닮은 항목·다른 항목을 살펴본다. 일수를 나란히 비교하며 결과가 나온 이유를 설명한다. ‘응답 수정하기’로 돌아가 바꾸면 결과도 달라진다.
4. **탐색**: 중분류·기준월·지표를 바꿔본다. 집단별 막대와 1~6월 추이, 수치 표를 보여준다. 집단 버튼으로 특정 선을 강조할 수 있다.
5. **조건 전환**: 데이터 안내에서 ‘시간 지표 포함’을 선택한다. 응답은 초기화되고 설문에 선택적 분 입력과 탐색의 시간 차트가 추가된다. ‘기본 데이터’로 바꾸면 모두 사라진다.

## 제한된 데이터도 보여주기

- 뉴스 읽기 / 2025년 6월: F집단은 비공개여서 ‘데이터 없음’이다. 구성비는 전체 비교 집단이 갖춰지지 않아 모든 집단에서 계산하지 않는다.
- 여행·나들이 / 2025년 3월: C집단 원본 행이 없다. 수치 표의 null과 선이 끊긴 추이를 확인한다.
- 1개 문항만 답한 후 뉴스/정보 분야로 이동해 결과를 제출한다. 부족한 항목 수와 설문 이어쓰기·탐색 안내가 나온다.
- 결과의 ‘비교에서 제외한 항목’을 열어 비공개·0일·무응답을 구분한다.

## 현재 구현 경계

- A~F는 실제 연령대가 아닌 시연용 가상 6집단이다. 실제 연령 경계는 수령 전까지 만들지 않는다.
- 수치·중분류명·비교 설정은 시연용이다. 결과는 실제 나이, 정확도, 개인 이용 기록을 뜻하지 않는다.
- 응답은 이 탭의 sessionStorage에만 임시 보관한다. 서버 저장·로그인·DB는 없다.
- Python이 산출한 profiles.json을 Spring이 읽고, Spring만 설문 유사도를 계산한다. 프론트엔드는 가짜 API 결과를 만들지 않는다.
- 실제 데이터 교체: 기본 코드북의 정의·분모·단위를 확인하고 Python 어댑터·설정을 바꾼 뒤 파이프라인을 실행한다.
  `APPBTI_PROFILES_PATH`를 실제 산출물로 지정하고 서버를 다시 실행한다. 실제 유사도 설정은 기본 off이므로 합의 후 활성화한다.
  실제 데이터에는 목업 시간 버전을 혼합하지 않는다.
